# 回信人 (letter-repliers)
心理微电影，8—10 分钟，五幕。
## 角色设定（5男演员，3男2女角色）
- 沈叙（男）：组长，最稳也最回避。
- 陆知（男）：回信人，话少，匿名信是他写的。
- 许澈（女，男演员反串）：撰稿，不想转专业。
- 泛华（女，男演员反串）：外联，最怕散场。
- 顾行（男）：新成员，怕不被需要。
## 场景
空教室、走廊、食堂角落、长椅、打印店门口。
## 核心规则
- 每幕最多一个可控笑点，第四幕无笑点。
- 笑点只来自演员自己的手机、提前做故障的道具、他们维护的信箱。
- 禁止依赖动物、随机路人、现场真实喇叭、偶遇保洁阿姨。
## 片头说明
本片部分角色由异性演员饰演，旨在探讨表达困境，不以性别反串为卖点。
