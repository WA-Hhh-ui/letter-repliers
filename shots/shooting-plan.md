# 《回信人》拍摄执行方案

依据：`story/script.md`（完整拍摄稿）、`notes.md`（拍摄执行规则）、`story/STORYBOARD.md` / `shots/shot-list.md`（分镜表模板）。
目标成片：8—10 分钟。五幕。5 名男演员饰演 3 男 2 女角色，许澈、泛华由男演员反串。
本方案用于落地拍摄：含场地、器材、通告、逐场逐镜拍摄要点、表演提示、后期与应急预案。

---

## 零、开机前必须锁死的六条红线

1. 每幕最多一个可控笑点，**第四幕不设笑点**。
2. 笑点来源只能是：演员自己的手机、提前做过故障的道具、他们维护的信箱。
3. 禁止：动物、随机路人、现场真实喇叭（招新/收废品）、偶遇保洁阿姨。
4. 反串边界：不模仿刻板女性、不捏嗓子、不扭捏、声音自然、服装中性、性别不是笑点。
5. 第三幕五个空间是平行剪辑，需一次性拍全，缺一条则情绪链断裂。
6. 结尾不许拥抱、不许和解演讲，只保留"开始允许自己被听见"的动作。

## 一、制作规格

| 项目 | 设定 |
|---|---|
| 成片时长 | 8—10 分钟（五幕合计约 9.5 分钟，留剪辑余量） |
| 画幅/比例 | 16:9，横向为主 |
| 叙事结构 | 第一幕建立 → 第二幕破规 → 第三幕扩散 → 第四幕高潮 → 第五幕落点 |
| 情绪曲线 | 平稳（1）→ 绷紧（2）→ 下沉（3）→ 静默峰值（4）→ 微光（5） |
| 摄影基调 | 固定机位为主、少量缓慢推拉；中近景叙事，特写只给手/纸/屏幕/眼神；第四幕禁运动 |
| 色彩基调 | 教室偏冷白日光，走廊冷绿，食堂暖黄，长椅黄昏偏蓝，打印店门口冷白+门外自然光 |
| 声音基调 | 环境声优先（翻纸、胶带、椅子、灯管、篮球、撕纸）；音乐只在片尾极轻进入或不进 |
| 笑点总数 | 全片 3 处（第一幕 sh010、第二幕 sh020、第五幕 sh050），每处拍三条 |

| 场景 | 用于 | 关键要求 | 布置要点 | 备选 |
|---|---|---|---|---|

## 三、器材与道具

### 3.1 器材（按低成本可执行配置）

- 机身 1—2 台（有手动曝光即可；双机用于第四幕对话正反打省时间）
- 三脚架 2 个（第四幕必须锁定，禁手持）
- 稳定器/滑轨：可选，仅第三幕平行剪辑的转场用
- 收音：领夹麦 2—3 支（对白主力现场收），机顶麦 1 支备用；第四幕务必双人各一支
- 灯光：LED 平板灯 1—2 盏 + 反光板（教室补阴面、长椅黄昏补眼神光）
- 监视器/监视 app、存储卡（≥64G×2）、备用电池、场记板
- 小道具收音辅助：手机外放用蓝牙小音箱（藏在课本/布袋内）以放大《运动员进行曲》声

### 3.2 道具清单

| 道具 | 用途 | 负责 | 状态要求 |
|---|---|---|---|
| 纸箱"解忧信箱" | 全片核心道具 | 美术 | 马克笔写字；胶带边角翘起；**第五幕需预先做松底**（见 5.3） |
| 信纸（三色） | 第一、二、五幕 | 美术 | 按颜色分三摞；准备足量空白回信纸 |
| 匿名信 | 第二、三、四幕 | 道具 | 无署名，一句话；**准备三份折痕版 + 复印件**（第四幕用） |
| 便签（规矩） | 第一幕 | 道具 | 沈叙手持，正面写满、背面空白 |
| 海报卷 + 图钉 | 第一、三幕 | 道具 | 可展开、可卷起横放膝上 |
| 手机×5 | 笑点1、第三幕、笑点2 | 演员自备 | 手机壳统一低调色；**预装《运动员进行曲》并关掉自动锁屏** |
| 小喇叭 | 笑点2 | 道具 | **提前把播放键旁录音换成"收旧书旧手机旧电脑"**（做故障） |
| 转专业申请表 | 第三幕许澈 | 道具 | 真实排版，右下"本人签字"空白；准备两份（一份撕） |
| 蓝牙小音箱 | 笑点1 | 录音/道具 | 藏课本下，手机连蓝牙外放 |

## 四、通告与排期（建议两天拍完 + 半天补拍）

**开机前 3 天**：围读剧本 2 次；确认反串边界与表演分寸；技术走位（尤其第四幕调度、笑点走位）；道具故障 testes（信箱松底、小喇叭录音、灯管闪烁）各做一次。

| 时段 | 场景 | 拍摄内容 | 备注 |
|---|---|---|---|
| D1 15:00—17:30 | 空教室 | 第一幕全部、第二幕全部 | 抢下午斜光；先拍无笑点的顺戏，最后拍笑点 sh010 |
| D1 17:30—18:00 | 空教室 | 第五幕（教室段） | 挨着拍省布景；信箱笑点 sh050 留最后 |
| D1 黄昏 | 走廊 | 第三幕沈叙 | 灯管闪烁可控；教室门开合走位 |
| D2 11:00—12:30 | 食堂角落 | 第三幕陆知 | 避开饭点高峰抢安静角 |
| D2 14:00—15:00 | 打印店门口 | 第三幕许澈 | 备好可撕表格 |
| D2 16:30—18:00 | 长椅 | 第三幕泛华 + 第四幕全段 | 黄昏光；第四幕占最多时间，机位锁定 |
| D2 18:00—18:30 | 长椅 | 篮球声收录（只收音不拍人） | 单独录 30 秒备用 |
| 补拍半天 | 机动 | 笑点三条补拍、特写补镜（手/纸/屏幕） | 剪辑发现问题统一补 |

> 排期原则：**同场景集中拍**。若场地只能借用一天，优先保第四幕与第二幕。

## 六、三处笑点的标准拍法（每处拍三条：正常 / 夸张 / 收着）

> 剪辑选最自然的一条。三条都必须来自同一合规来源，不得临场加入动物、路人、真实喇叭、保洁阿姨。

### 5.1 笑点1 — 顾行手机《运动员进行曲》（sh140）

- **来源**：演员自己的手机（合规）。提前把手机连蓝牙小音箱藏课本下，音量渐强可控。
- **走位**：顾行坐桌前，手机在口袋→抽屉→课本底下，三段递进。
- **三条**：①正常：越按越响两下就闷住；②夸张：连按四五下、屏幕乱闪（备选，慎选）；③收着：只响一截就停，全靠表情。
- **沈叙反应**：只一眼，继续念规矩——**不许笑、不许停顿**。
- **剪辑**：推荐正常条；声音做"闷—亮—更闷"的层次，别一刀切。

### 5.2 笑点2 — 泛华小喇叭按错（sh220）

- **来源**：提前做成故障的道具（合规）。前一天把小喇叭播放键旁录音换成"收旧书旧手机旧电脑"。
- **关键**：落点是**没有人笑**（sh240）。这是"冷场笑点"，不是"逗笑笑点"。
- **三条**：①正常：按错→播一句→按掉；②夸张：多播半句、手忙脚乱；③收着：刚出声就掐断。
- **禁忌**：泛华不许挤眉弄眼、不许看镜头；顾行全程看信不看喇叭。

### 5.3 笑点3 — 信箱底裂开（sh820）

- **来源**：他们维护的信箱（合规）。**提前做松底**：箱底胶带只粘一半、剪开一道暗口，彩排时不裂，正式拍时轻按即塌。
- **安全**：信纸用 disposable 张，底下垫软布防摔；别用硬物砸箱。
- **三条**：①正常：底塌一角、信滑出、五人蹲下捡；②夸张：信撒得更开、有人膝盖碰桌（备选）；③收着：只裂一条缝、两三张滑出。
- **表演**：泛华肩膀抖一下即可，**不许出声笑**；顾行按信确认箱底——笑点落在"道具不可靠但人还在维护"，不是滑稽。
- **落点镜**：sh830 箱子往里挪半寸，无台词，别配乐强调。

## 八、后期方案

1. **剪辑结构**：严格五幕；第三幕用"每个空间结尾的静止镜头"做交叉点；第四幕少切、长镜；第五幕笔尖声做节奏。
2. **笑点剪辑**：每处从三条里选最自然一条；正常条优先；笑点后立即接冷场镜（sh240 / sh150 / sh830），防止包袱散掉。
3. **声音**：环境声垫底（翻纸、胶带、椅子腿、灯管、汤勺、撕纸、篮球）；对白优先清晰；音乐只在片尾极轻进入（sh870），或不进。
4. **调色**：教室冷白、走廊冷绿、食堂暖黄、长椅黄昏偏蓝；全片低饱和，避免滤镜感。
5. **片头说明**：按剧本文字原样上屏——"本片部分角色由异性演员饰演，旨在探讨表达困境，不以性别反串为卖点。"
6. **检查点**：粗剪（结构/时长）→ 精剪（表演/节奏）→ 终剪（声音/调色/字幕）三关。

## 九、应急预案

| 风险 | 预案 |
